# CertSentry 证书哨兵

面向中小团队和个人站长的 SSL/TLS 证书与域名到期监控平台。支持邮件以及企业微信、钉钉、飞书群机器人告警，可开源自部署。

## 为什么做这个

- 2025 年 4 月 CA/Browser Forum 通过 SC-081：TLS 证书最长有效期自 2026-03-15 起降为 200 天，2027 年降为 100 天，2029 年降为 47 天。
- Let's Encrypt 已于 2025-06-04 停止发送证书到期提醒邮件。
- 现有工具要么只检查到期天数，要么面向大企业、价格高，且不支持国内常用的群机器人。

## 计划功能

- 定时检测证书有效期、证书链、域名匹配、弱算法，逐 IP 发现多节点证书不一致
- 分级到期告警（30/14/7/3/1 天），告警去重、静默、恢复通知
- 基于 CT 日志的子域名证书资产发现（需 DNS 验证域名归属）
- 多租户组织与角色权限、REST API、状态徽章、公开状态页

## 技术栈

FastAPI · SQLAlchemy 2.1（asyncio）· PostgreSQL · Redis · Alembic · Vue 3 + TypeScript · Docker

检测引擎是独立的 asyncio worker，多个实例通过 PostgreSQL `FOR UPDATE SKIP LOCKED` 并发领取任务；通知通过事务性 outbox 表投递，保证不丢不重。
